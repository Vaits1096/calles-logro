# Calles de Logroño

Juego en el navegador: se ilumina una calle de Logroño sobre un mapa satélite y hay que elegir su nombre entre 4 opciones. Se ven los nombres de las calles vecinas, pero no el de la calle que hay que adivinar.

Abre `calles_logrono.html` en el navegador (necesita conexión a internet para las imágenes).

- Calles: © colaboradores de OpenStreetMap (ODbL), incrustadas en el HTML.
- Controles: `1`–`4` responder, `Enter` siguiente ronda, `C` centrar la calle.
